🧠 認知與記憶 (Cognition & Memory)

Cognition Memory

1. 艾賓浩斯遺忘曲線 (Ebbinghaus Forgetting Curve)

德國心理學家艾賓浩斯研究發現，記憶的遺忘在學習後最初一段時間最快，隨後逐漸平緩。

2. 訊息處理模型 (Information Processing Model)

  • 感官記憶 (Sensory Memory)：訊息停留時間極短（約數秒）。
  • 短期記憶 (Short-term Memory)：容量約為 7±2 個項目。
  • 長期記憶 (Long-term Memory)：容量無限，可長期儲存知識與經驗。
